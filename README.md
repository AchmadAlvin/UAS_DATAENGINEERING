# UAS Data Engineering

Repositori tugas UAS Data Engineering.

## Struktur

- `notebooks/` — notebook analisis utama.
- `data/raw/` — dataset mentah CSV.

## Cara menjalankan

1. Buka `notebooks/LAPORAN_TEAM_PROJECT_2.ipynb`.
2. Jalankan sel dari awal sampai akhir.
3. Pastikan file CSV tetap berada di `data/raw/`.

Notebook juga mempertahankan fallback path `/content` untuk eksekusi di Google Colab.
